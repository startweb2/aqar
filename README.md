# Alamein Towers Luxury Showcase | مشروع أبراج العلمين الفاخرة 🌊✨

منصة عرض معمارية فاخرة وفائقة التطور لمشروع **أبراج العلمين الجديدة**، بتصميم متوسطي مستوحى من أعلى معايير الرفاهية العالمية، مع دعم كامل ومزدوج للغتين العربية (RTL) والإنجليزية (LTR)، وتسلسل فيديو دروني ثلاثي الأبعاد تفاعلي فائق السلاسة (210 إطار سينمائي بدقة عالية).

---

## 🌟 المميزات الرئيسية (Key Highlights)

- 💎 **هوية بصرية متوسطية فاخرة (Mediterranean Architectural Luxury)**:
  - تناسق لوني ساحر يجمع بين الأسود الملكي (`Midnight Black`)، ولمسات الذهب الشامباني (`Champagne Gold #DFB76E`)، والعاجي الدافئ (`Warm Ivory`).
  - خطوط طباعية متقنة: `Cairo` للغة العربية، و`EB Garamond` للعناوين الإنجليزية، و`Plus Jakarta Sans` للمحتوى.
- 🎬 **تسلسل دروني سينمائي تفاعلي (Cinematic 3D Drone Sequence Player)**:
  - مشغل `<canvas>` فائق الأداء يعرض 210 إطارات سينمائية بطائرة دريون حول أبراج العلمين.
  - دعم معدل التحديث الطبيعي (24fps)، تحجيم تلقائي حسب كثافة بكسل الشاشة (DPR Scaling)، زر إيقاف/تشغيل، ومؤشر للإطارات الحية، مع إمكانية عرض فيديو تعريفي فوري.
- 🌐 **دعم كامل للغة العربية والإنجليزية (Full Bilingual RTL/LTR)**:
  - واجهة عربية أصيلة بنسبة 100% مع تبديل لحظي ودون إعادة تحميل.
  - تعديل اتجاه الصفحة (`dir="rtl"` / `dir="ltr"`) وتغيير الخطوط تلقائياً.
- 🏢 **مستكشف الوحدات السكنية (Curated Residences Collection)**:
  - فلترة سريعة وتفاعلية حسب عدد الغرف (غرفة، غرفتان، 3 غرف، وبنتهاوس).
  - مصفوفة مقارنة معمارية تفصيلية (Comparison Matrix) للمساحات والارتفاعات والمسابح الخاصة.
- 📐 **مستعرض المخططات الهندسية والمساحية (Spatial Cadastre & Floor Plans Explorer)**:
  - مخططات هندسية أيزومترية تفاعلية بمتجهات SVG واضحة الدقة.
  - حساب مساحات الغرف الصافية، ونسب التراسات الخارجية، وجداول الخامات والتشطيبات الفاخرة (Travertine, Carrara Marble, Brushed Brass).
- 🛎️ **حجز المعاينات والكونسيرج الخاص (Private VIP Concierge & Booking)**:
  - نموذج حجز زيارة خاصة مع دعم خدمات الاستقبال الملكي (نقل بسيارات خاصة، إرساء اليخوت بمارينا العلمين، وعرض هولوجرامي ثلاثي الأبعاد).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend Core**: React 18, TypeScript
- **Bundler & Tooling**: Vite 6
- **Styling**: Tailwind CSS (JIT, Custom Luxury Design Tokens, RTL Utilities)
- **Typography**: Google Fonts (`Cairo`, `EB Garamond`, `Plus Jakarta Sans`, Material Symbols)
- **Routing**: React Router DOM 6

## 🚀 التشغيل محلياً (Getting Started)

1. **استنساخ المستودع (Clone the repository):**
   ```bash
   git clone https://github.com/startweb2/aqar.git
   cd aqar
   ```

2. **تثبيت الحزم (Install dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل خادم التطوير (Run development server):**
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

4. **بناء النسخة الإنتاجية (Build for production):**
   ```bash
   npm run build
   ```
